# 03 · 数据结构（v2 · 严格按功能清单）

> 约定：沿用现有 `dm` 前缀标签、引用闭合、`dmSynthetic` 标记模拟数据、`dmDataset` 防重放、ID 前缀 `dm-*`。
> 每条结构标注对应功能编号；功能清单之外不建任何记录类型或标签。
> 历史不自建存储：监测点经标准 Haystack `his` 机制由连接器写入，本系统只读（hisRead）。

## §1 现有结构（F1.4/F1.5 复用）

- site 记录（site 标记）、floor 记录（floor 标记 + siteRef/floorNum）。
- 设备：equip + dmDevice 标记；标签 dmCode/dmModule/dmType/dmSite/dmFloor/dmStatus/dmQuality/dmMetric/dmUnit/dmValue/dmUpdatedAt/dmManufacturer/dmModel。
- 点位：point + sensor 标记 + equipRef + kind/unit + dmQuality/dmValue。
- F1.4 实时值：读 point 的 curVal（无 curVal 时回退 dmValue 快照并标注来源）。
- F1.5 历史：hisRead(point, range)；点位需带 `his` 标记才有历史。

## 通用约束

- 所有新记录带 dmDataset（如 `deviceManager-demo-v2`）与 dmProvenance；模拟集全部加 dmSynthetic。
- 引用必须闭合；枚举值集中在 fixtures，前端与 seed 共用。
- 真实点位数据（连接器写入的 curVal/his）不带 dmSynthetic；界面区分来源展示（沿用现有 source 标记）。
- 本清单外无任何记录类型/标签；后续新增功能须先回到 02 功能清单增补。
