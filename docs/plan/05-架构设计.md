# 05 · 架构设计（v2 · 前端 / 后端）

## 1. 总体架构

```
FIN 平台（宿主）
 ├─ 连接器/采集：写入 point curVal + his（本系统不实现，只读）
 ├─ deviceManager POD
 │   ├─ res/web/dm     前端 React 应用（新增页面与 provider）
 │   ├─ lib (Fantom)   只读信息 + 受控写函数（I-W1…I-W9）
 │   └─ ext            扩展注册（不变）
 └─ 记录库：equip/point/dmDoc/工单/检测/报警/计划/自评 等 Haystack 记录
```

不引入独立后端服务；读走 FIN 会话，写走 lib 函数（见 04 接口清单）。本系统保持"观察 + 记录型写入"，不做设备控制闭环，不做能耗模块（见 00 差距分析 2.3）。

## 2. 前端（ts/）

- 技术栈不变：React 19 / Vite / React Router 7 / Recharts 3。
- 路由新增（严格对应 02 功能清单"功能—页面映射"）：
  - `/workorders`（F1.2）、`/inspections`（F1.3）、`/environment`（F2.1）、`/alarms`（F2.2）、`/water`（F2.3）、`/plans`（F3.1）、`/assessment`（F3.2）。
- 设备详情新增「档案」「运维记录」标签（F1.1/F1.2），点位区显示实时值与历史曲线（F1.4/F1.5）。
- provider 层（`ts/src/data/provider.js`）：每个 I-R/I-W 接口定义 local / fin 双实现，签名与 04 清单一一对应；fin 实现经 haystack-nclient 宿主会话，历史经 hisRead。
- fixtures（`ts/src/data/fixtures.js`）：枚举（工单类型/检测对象/报警严重级/计划系统/用水分项/IAQ 种类）唯一来源，seed 脚本与前端共用。
- 新增组件：WorkOrderTable、InspectionForm、DeviceTimeline、IaqPanel、AlarmCenter（确认/关闭）、WaterReport（月报+CSV）、PlanBoard、ScoreSheet。
- 沿用既有体验约束：错误/空/未知态、来源标注（synthetic vs 真实）、桌面+移动布局、键盘导航、CSV 导出。

## 3. 后端（FIN POD）

- `fan/DeviceManagerLib.fan`：新增 I-W1…I-W9 写函数。每个函数：参数校验 → 冲突/防重放检查 → diff(null, rec, {add}) 或受控状态迁移 → 返回记录 id。异常抛错不静默。
- 种子脚本：`scripts/seed-data.mjs` 扩展生成新记录类型（`deviceManager-demo-v2`：dmDoc/工单/检测/IAQ 点/报警规则与事件/水表/中水记录/计划/自评条目），仍走"confirmed=false 预览 + 用户确认"流程；防重放沿用 dataset 冲突拒绝。
- 历史数据：不自建采集；curVal/his 由现场连接器提供。模拟模式用 fixtures 生成确定性历史曲线（标注 Synthetic）。

## 4. 数据流示例（F2.2 报警闭环）

1. IAQ 点 curVal/his 由连接器写入 FIN；规则由 I-W5 登记为 dmAlarmRule 记录。
2. 报警产生途径：现场规则引擎写入 dmAlarmEvent，或导入脚本按规则批量生成（模拟模式）。
3. 前端 AlarmCenter 经 I-R9 拉取事件流，确认/关闭走 I-W6 状态迁移，留痕可审计。

## 5. 构建与验证

- 沿用 `scripts/build.ps1`：npm ci → 单测 → seed 预览 → 离线 Axon 解析 → 构建 → 资源哈希核对。
- 新增单测：provider 双实现等价性（同 fixtures 输入同输出）、工单状态机合法性（I-W2）、报警状态机合法性（I-W6）、防重放拒绝。
- e2e（Playwright）：工单创建→设备时间线可见；CO2 超限→报警事件→确认→关闭；用水月报空态/导出。
- 边界声明：编译与离线解析不证明现场扩展启用；现场验收另行列项。

## 6. 分支与提交策略

- `developer` 分支开发；每个功能（F 编号）一个小步提交，提交信息带 F 编号与需求编号。
- 计划文档先行：任何代码改动必须能追溯到 01→02→03→04→05 的条目；结构或接口的变更必须先改 02/03/04 文档再动代码。
