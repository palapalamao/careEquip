# 00 · 绿色医院建筑评价标准差距分析

> 依据：《绿色医院建筑评价标准（征求意见稿）》GB/T 草案（`docs/refdocs/绿色医院建筑评价标准_1509`）
> 对象：careEquip / deviceManager 设备管理工作台（FIN POD）
> 日期：2026-09-18

## 1. 系统现状摘要

当前系统是医院后勤**设备观察**工作台：设备总览、台账、异常清单、8 个系统分类（暖通、配电、给排水、照明、电梯、安全、医疗空间、医疗设备）、搜索筛选、CSV 导出、设备详情、点位读数、24 小时模拟趋势。

数据模式：FIN 记录 + `dmValue` 主读数**快照**；不写 curVal、不建立连接器、不写历史；FIN 模式历史页显示"暂无可用历史"。异常仅由设备状态（fault/offline）派生，无阈值报警规则。无能源、无运维工单、无环境品质、无计划管理功能。

## 2. 差距对照表

### 2.1 控制项（不满足则无法参评，最高优先级）

| 标准条款 | 要求 | 系统现状 | 差距 |
|---|---|---|---|
| 9.1.1 | 设施设备经法定机构验收合格并正常使用；**档案资料完整，运行、维护记录全面、详尽、及时、真实** | 有台账（编码/名称/位置/厂商/型号），无验收资料、无运维记录 | **大**：缺设备档案（验收文件、投用日期）与运行维护记录模块 |
| 9.1.2 | 对饮用水、医疗用水、非传统水源、医用气体、空调、污水处理、医疗废物、射线防护、室内环境**日常维护和定期检测，有内部检测记录** | 无 | **大**：缺定期检测/巡检记录管理 |
| 9.1.3 | 建立节地节能节水节材管理制度并执行 | 制度文本非软件范畴 | 小：可作为文档附件管理 |

### 2.2 高分值评分项（软件系统可直接支撑）

| 标准条款 | 分值 | 要求 | 系统现状 | 差距 |
|---|---|---|---|---|
| 9.2.8 能源资源计量、审计、绩效考核 | **20** | 分级计量到部门；用电/用水/用气**同比下降**（>10% 得高分）；能源审计；奖惩措施 | 无任何能耗数据 | **大**：缺分项能耗计量、同比分析、审计与 KPI 记录 |
| 5.2 建筑能耗分项计量 | **16** | 按建筑单体、功能区分区计量；功能区内按照明、医疗办公、空调、电梯、给排水等**分项计量**；查阅**逐年月日记录** | 8 个系统分类已有基础，但无计量数据、无历史 | **大**：缺计量点模型与历史存储 |
| 8.2 室内空气质量监控 | 7 | 高密度区域 CO2 数据采集分析并与新风联动；污染物**超标实时报警** | 无环境类别；报警仅由状态派生 | **大**：缺 IAQ 点位、阈值报警规则与报警事件流 |
| 9.2.7 智能化系统实时监控 | 5 | 智能化系统纳入医院信息系统统一管理，对设施设备运行**实时监控** | 仅快照读数，无 curVal/历史 | **中**：需接入实时值与历史（hisRead） |
| 9.2.6 运行计划 | 5 | 医用气体、电力、空调、供水、蒸汽、供热等系统的运行计划及年度执行考核 | 无 | **中**：缺运行计划与执行记录 |
| 9.2.9 设施设备维护改造 | 4 | 维护、改造有记录，选用绿色技术产品 | 无 | 并入运维记录模块 |
| 6.2 节水与水资源利用 | 多项 | 用水计量、非传统水源利用（中水/雨水）、管网漏损控制 | 给排水仅有设备台账 | **中**：缺用水计量与非传统水源记录 |
| 9.2.8 可再生能源利用 | 含于 20 分 | 太阳能等可再生能源利用记录 | 无 | 低：记录型功能 |
| 5.2 设备能效 | 14 | 锅炉、冷机、变压器、水泵风机**能效指标**符合节能产品要求 | 台账有厂商/型号，无能效字段 | 低：台账扩展字段 |

### 2.3 非软件范畴（不纳入系统需求）

9.2.1 组织机构与培训、9.2.2 管理体系认证、9.2.3 绿地、9.2.4 室外休息区、9.2.5 绿色出行、9.2.10 化学品、9.2.11 医疗废物、9.2.12 施工影响、第 4/7 章（场地、节材）。

## 3. 差距总结（按优先级）

1. **历史与实时数据接入**（一切分析的前提）：当前只有快照 `dmValue`，标准反复要求"逐年月日记录"和"实时监控"。需接入 curVal 与 hisRead，或建立采集写入通道。
2. **运维证据链**（控制项 9.1.1 / 9.1.2 / 9.2.9）：设备档案 + 运行维护记录 + 定期检测记录，是参评的硬性门槛，当前完全缺失。
3. **能耗分项计量与同比分析**（16+20 分）：分区/分项计量模型 + 日月年记录 + 同比 KPI。
4. **室内环境质量与报警联动**（7 分）：CO2 等 IAQ 点位、阈值规则、超标报警事件。
5. **运行计划管理**（5 分）：面向医用气体/电力/空调/供水/蒸汽/供热的计划与年度考核。
6. **台账扩展**：验收日期、能效等级、额定参数等字段（低成本，随档案模块一起做）。

## 4. 已有基础的复用

- 8 个系统分类与标准"分项计量"的系统划分（照明/暖通/电梯/给排水/医疗）基本对齐，可直接作为能耗分项的归类维度。
- FIN 平台本身满足 9.2.7"智能化系统纳入医院信息系统统一管理"的定位，扩展读写均走 FIN 记录模型，不需要引入新后端服务。
- 设备—点位两级记录结构（equip + point）可直接扩展挂载计量点、IAQ 点和运维记录引用。
