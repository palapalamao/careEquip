# 00 · 绿色医院建筑评价标准差距分析（v2 · 不含能耗）

> 依据：《绿色医院建筑评价标准（征求意见稿）》GB/T 草案（`docs/refdocs/绿色医院建筑评价标准_1509`）
> 对象：careEquip / deviceManager 设备管理工作台（FIN POD）
> 日期：2026-09-18 · v2：剔除能耗相关需求（分项计量 5.2、能源审计绩效 9.2.8、可再生），重新推导

## 1. 系统现状摘要

当前系统是医院后勤**设备观察**工作台：设备总览、台账、异常清单、8 个系统分类（暖通、配电、给排水、照明、电梯、安全、医疗空间、医疗设备）、搜索筛选、CSV 导出、设备详情、点位读数、24 小时模拟趋势。

数据模式：FIN 记录 + `dmValue` 主读数**快照**；不写 curVal、不建立连接器、不写历史；异常仅由设备状态派生，无阈值报警规则。无运维工单、无检测记录、无环境品质、无计划管理功能。

## 2. 差距对照表（本期范围内）

## 3. 差距总结（按优先级）

1. **历史与实时数据接入**（一切监测分析的前提）：当前只有快照 `dmValue`，标准 9.2.7 要求"实时监控"、8.2 要求连续采集分析。需接入 curVal 与 hisRead。
2. **运维证据链**（控制项 9.1.1 / 9.1.2 / 9.2.9）：设备档案 + 运行维护工单 + 定期检测记录，是参评硬性门槛，当前完全缺失。
3. **室内环境质量与报警联动**（8.2，7 分）：CO2 等 IAQ 点位、阈值规则（CO2 > 1000 ppm）、报警事件流。
4. **用水与节水**（6.2）：用水分项计量、非传统水源利用记录。
5. **运行计划管理**（9.2.6，5 分）：面向医用气体/电力/空调/供水/蒸汽/供热的计划与年度考核。
6. **台账扩展**：验收日期、投用日期等档案字段（低成本，随档案模块一起做）。

## 4. 已有基础的复用

- 8 个系统分类覆盖标准运维/监测涉及的主要系统（暖通、配电、给排水、医用气体属暖通/医疗空间、电梯、照明）。
- FIN 平台满足 9.2.7"智能化系统纳入医院信息系统统一管理"的定位；扩展读写均走 FIN 记录模型，不引入新后端服务。
- 设备—点位两级记录结构（equip + point）可直接扩展挂载 IAQ 点、水表点和运维记录引用。
