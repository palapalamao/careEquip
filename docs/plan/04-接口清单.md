# 04 · 接口清单（v2 · 严格按功能清单）

> 每个接口标注对应功能编号；**功能清单之外不设接口**。
> 读：经 provider 层走 FIN 会话（haystack-nclient）；写：经 lib 受控 Axon 函数，只增不改 + 状态机校验 + 防重放。

## 1. 读接口

| 编号 | 接口 | FIN 实现 | 功能 |
|---|---|---|---|
| I-R1 | 设备列表（含档案扩展字段） | `readAll(dmDevice, {limit:1000})`，读取 dmCommissionDate/dmInServiceDate/dmAcceptanceDocRef；v0.4.0 起同时读 dmPurchaseCost/dmAnnualBenefit/dmRatedValue | F1.1/F4.3 |
| I-R2 | 设备关联记录时间线 | `readAll(dmWorkOrder and dmDeviceRef==@id)` + `readAll(dmInspection and dmDeviceRef==@id)` 合并按时间排序 | F1.1/F1.2/F1.3 |
| I-R3 | 工单列表 | `readAll(dmWorkOrder …)` 按状态/类型/时间过滤，分页 | F1.2 |
| I-R4 | 检测记录列表 | `readAll(dmInspection …)` 按检测对象/结论/时间过滤，分页 | F1.3 |
| I-R5 | 实时读数 | `readById(pointId)` 取 curVal；无 curVal 回退 dmValue 并标注快照来源 | F1.4 |
| I-R6 | 历史曲线（通用） | `hisRead(pointId, range)` 日/周/月/年；IAQ 与水表点位共用 | F1.5/F2.1/F2.3 |
| I-R7 | IAQ 点位列表 | `readAll(point and dmIaq)` 按 roomRef/floorRef 分组 | F2.1 |
| I-R8 | 用水分项读数 | `readAll(equip and dmWaterMeter)` 取水表集合，对其 point 做 hisRead 按月聚合 | F2.3 |
| I-R9 | 报警事件列表 | `readAll(dmAlarmEvent …)` 按 dmAlarmStatus/dmRuleSeverity/时间过滤 | F2.2 |
| I-R10 | 非传统水源记录 | `readAll(dmWaterReuse …)` 按 dmReuseKind/dmReusePeriod 过滤 | F2.3 |
| I-R11 | 计划与执行记录 | `readAll(dmPlan …)` + `readAll(dmPlanExec …)` 按 dmPlanSystem/period | F3.1 |
| I-R12 | 自评条目列表 | `readAll(dmScoreItem …)` 按 dmClause 排序 | F3.2 |
| I-R13 | 年度考核结论 | `readAll(dmPlanReviewRec …)` 按 dmReviewSystem/dmReviewYear | F3.1（v0.3.2 新增） |
| I-R14 | 设备利用率聚合 | lib 只读函数 `dmComputeUtilization(days)`，days∈7/30/90：readAll 设备→各自 primary point→hisRead 聚合，返回每设备 开机率/使用时长/负荷率/峰值负荷/样本数；无 his 或无 dmRatedValue 的设备返回明确空态字段，不伪造 | F4.1（v0.4.0 新增） |

## 2. 写接口（lib 受控函数）

写入原则：参数校验 → 冲突/防重放检查（dmDataset）→ `diff(null, rec, {add})`；唯一允许的"改"是状态迁移，函数内做合法性检查并留痕操作人与时间。

| 编号 | 函数 | 说明 | 功能 |
|---|---|---|---|
| I-W1 | dmCreateWorkOrder(dict) | 新建工单（校验 dmDeviceRef 存在）；**v0.4.0 起 dict 可含 dmWoCost（元，可选）** | F1.2/F4.2 |
| I-W2 | dmTransitWorkOrder(id, target, note) | open→inProgress→closed 单向迁移，拒绝跳变/回退；**target=closed 时 note（执行结果）必填，写入 dmWoResult（v0.3.2 收紧）** | F1.2 |
| I-W3 | dmSaveDeviceProfile(id, patch) | 补充档案字段：仅允许空→有，不覆盖既有值；**v0.4.0 起 patch 可含 dmPurchaseCost/dmAnnualBenefit/dmRatedValue** | F1.1/F4.3 |
| I-W4 | dmCreateInspection(dict) | 新建检测记录 | F1.3 |
| I-W5 | dmSaveAlarmRule(dict) | 新建/停用报警规则（停用=新增停用标记，不改历史规则） | F2.2 |
| I-W6 | dmAckAlarm(id) / dmCloseAlarm(id) | active→acknowledged→closed 状态迁移 | F2.2 |
| I-W7 | dmRecordWaterReuse(kind, period, amount) | 登记中水/雨水利用量（同 period+kind 重复登记拒绝） | F2.3 |
| I-W8 | dmCreatePlan(dict) / dmRecordPlanExec(dict) | 计划与执行登记（校验 dmPlanRef 闭合） | F3.1 |
| I-W9 | dmSaveScoreItem(dict) | 自评条目评分与证据挂接（证据 ref 必须存在） | F3.2 |
| I-W10 | dmSavePlanReview(system, year, summary, conclusion) | 年度考核结论落库；同一 system+year 覆盖更新（派生汇总，非原始证据，documented 例外）；system/year/结论枚举校验 | F3.1（v0.3.2 新增） |
| I-W11 | dmBackfillSyntheticCosts() | 演示数据一次性成本回填：仅 update dmSynthetic 记录——模拟工单按类型确定性成本 200~8000 元（写 dmWoCost）、模拟设备采购成本按模块档位 5~80 万（dmPurchaseCost）、年收益 1~20 万（dmAnnualBenefit）、dmRatedValue=base；防重放：任一模拟工单已有 dmWoCost 则整体拒绝；**documented 例外**：只动模拟数据，真实工单/用户数据一律不动 | F4.2/F4.3（v0.4.0 新增） |
| I-W12 | dmSeedSyntheticHistory() | 演示历史种子：48 个演示点位 hisWrite 近 30 天逐小时历史（昼夜/工作日节律 + 2 台闲置 + 1 台过载 storyline，确定性伪随机）；防重放：hisSize>0 的点位跳过；完成后点位补 his 标记；**documented 例外**：只写模拟点位 | F4.1（v0.4.0 新增） |

备选方案：前端直接发 `diff/commit` 表达式——不推荐，绕过校验与防重放。

## 3. 本地模拟

provider 的 local 实现对上述接口返回 fixtures 数据集（扩展 seed-data，覆盖新记录类型），保证离线开发与演示；FIN 失败不回退模拟（沿用现有原则）。

## 4. 验收口径

- 读接口无数据时返回明确空态；FIN 错误如实透传。
- 写接口重复提交（同 dmDataset）被拒绝并提示。
- 无 his 的点位返回空序列，前端展示"暂无可用历史"。
- 非法状态迁移（工单/报警）在 lib 侧抛错。
