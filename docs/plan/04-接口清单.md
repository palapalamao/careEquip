# 04 · 接口清单

> 前端不直接拼 Axon 字符串业务逻辑，统一经 provider 层；读走现有 FIN 会话（haystack-nclient），写走 lib 新增受控 Axon 函数。

## 1. 读接口（FIN 表达式 / 调用）

| 编号 | 接口 | FIN 实现 | 前端 provider | 需求 |
|---|---|---|---|---|
| I-R1 | 设备列表（含档案扩展字段） | `readAll(dmDevice, {limit:1000})`（扩展读取 dmCommissionDate 等） | fetchDevices | R1 |
| I-R2 | 设备关联记录 | `readAll(dmWorkOrder and dmDeviceRef==@id …)` 按设备反查工单/检测 | fetchDeviceTimeline | R2 |
| I-R3 | 工单/检测列表 | `readAll(dmWorkOrder …)` / `readAll(dmInspection …)` 加分页过滤 | fetchWorkOrders / fetchInspections | R2 |
| I-R4 | 实时读数 | `readById(pointId)` 取 curVal（fallback dmValue 快照并标注来源） | fetchLiveValue | R3.1 |
| I-R5 | 历史曲线 | `hisRead(pointId, range)` 日/周/月/年 | fetchHistory | R3.2 |
| I-R6 | 计量点树 | `readAll(dmMeter …)` + 关联 point | fetchMeters | R4 |
| I-R7 | 能耗汇总 | hisRead 按计量点集合聚合（前端聚合或 Axon 聚合函数） | fetchEnergySummary | R4/R5 |
| I-R8 | 同比数据 | 同上，双周期对比 | fetchEnergyYoY | R5.2 |
| I-R9 | IAQ 点位 | `readAll(point and dmIaq …)` 或按房间 ref 过滤 | fetchIaqPoints | R6.1 |
| I-R10 | 报警事件 | `readAll(dmAlarmEvent …)` 按状态过滤 | fetchAlarmEvents | R6.3 |
| I-R11 | 计划/执行 | `readAll(dmPlan …)` / `readAll(dmPlanExec …)` | fetchPlans | R8 |
| I-R12 | 审计/KPI/奖惩/可再生 | 对应 readAll | fetchAudits / fetchKpi … | R5 |

## 2. 写接口（lib 受控 Axon 函数，只增不改 + 状态机迁移）

写入原则：输入校验、防重放（dmDataset 冲突拒绝）、只增不改；唯一允许"改"的是工单/报警的状态字段迁移，函数内部做合法性检查并记录操作人与时间。

| 编号 | 函数 | 说明 | 需求 |
|---|---|---|---|
| I-W1 | dmCreateWorkOrder(dict) | 新建工单 | R2.1 |
| I-W2 | dmTransitWorkOrder(id, targetStatus, note) | open→inProgress→closed 合法迁移 | R2.1 |
| I-W3 | dmCreateInspection(dict) | 新建检测记录 | R2.2 |
| I-W4 | dmSaveDeviceProfile(id, patch) | 档案扩展字段补充（仅限空→有，不覆盖既有值，防篡改） | R1 |
| I-W5 | dmAckAlarm(id) / dmCloseAlarm(id) | 报警确认/关闭 | R6.3 |
| I-W6 | dmCreatePlan / dmRecordPlanExec | 计划与执行登记 | R8 |
| I-W7 | dmCreateAudit / dmCreateReward / dmRecordRenewable | 审计/奖惩/可再生记录 | R5 |
| I-W8 | dmSaveScoreItem | 自评评分项（P2） | R9 |

备选方案：前端直接发 `diff/commit` 表达式。不推荐——绕过校验与防重放，权限边界不清。

## 3. 本地模拟接口

provider 的 local 实现对上述接口返回 fixtures 数据集（扩展 seed-data，覆盖新记录类型与时间线），保证离线开发与演示；FIN 失败不回退模拟（沿用现有原则）。

## 4. 验收口径

- 每个读接口在无数据时返回明确空态；FIN 错误如实透传。
- 写接口重复提交（同 dmDataset）必须被拒绝并给出提示。
- 历史接口对无 his 的点位返回空序列，由前端展示"暂无可用历史"。
