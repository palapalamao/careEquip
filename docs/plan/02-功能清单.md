# 02 · 功能清单（v2 · 不含能耗）

> 由 `01-需求定义.md` 派生；**数据结构与接口清单必须逐条以本清单为准，不允许出现清单外功能**。
> 优先级：P0 = 控制项/功能前提；P1 = 高分评分项；P2 = 增强。

## P0 — 第一期：证据链与数据地基

| 编号 | 功能 | 需求 | 验收口径 |
|---|---|---|---|
| F1.1 设备档案扩展 | R1 | 台账新增验收日期/投用日期/验收资料引用字段；详情页新增「档案」区与档案时间线 | R1.1/R1.2 |
| F1.2 运维工单 | R2.1/R2.3 | 工单列表、创建、状态迁移（open→inProgress→closed）；设备时间线聚合工单与检测记录 | R2.1/R2.3 |
| F1.3 定期检测记录 | R2.2/R2.3 | 检测记录列表、创建；检测对象枚举（10 项，对齐 9.1.2 控制项）；结论与报告附件引用 | R2.2 |
| F1.4 实时值接入 | R3.1 | FIN 模式读 point 的 curVal，详情页实时读数并标注来源 | R3.1 |
| F1.5 历史接入 | R3.2 | hisRead 日/周/月/年曲线；无历史时显示"暂无可用历史" | R3.2/R3.3 |

## P1 — 第二期：环境监测与用水

| 编号 | 功能 | 需求 | 验收口径 |
|---|---|---|---|
| F2.1 IAQ 监测 | R4.1 | 按房间/功能区展示 CO2（必选）、PM2.5、甲醛等点位实时值与历史曲线 | R4.1 |
| F2.2 报警规则与事件流 | R4.2/R4.3/R4.4 | 阈值规则配置（指标/操作符/阈值/严重级/联动设备）；报警触发、确认、关闭；按状态过滤 | R4.2~R4.4 |
| F2.3 用水分项与非常规水源 | R5.1/R5.2/R5.3 | 用水分项（生活/医疗/空调补水/其他）月报查询与 CSV 导出；中水/雨水利用记录登记与统计 | R5.1~R5.3 |

## P2 — 第三期：管理闭环

| 编号 | 功能 | 需求 | 验收口径 |
|---|---|---|---|
| F3.1 运行计划管理 | R6.1/R6.2 | 按系统（医用气体/电力/空调/供水/蒸汽/供热）建计划；执行登记；年度考核汇总与结论落库（I-W10，可跨年查询） | R6.1/R6.2 |
| F3.2 绿色医院自评表 | R7.1/R7.2/R7.3 | 评分条目维护、自评分、证据挂接（非能耗项）、导出 | R7.1~R7.3 |

## 功能—页面映射

- 设备详情页：新增「档案」「运维记录」标签；点位区显示实时值与历史曲线（F1.1/F1.2/F1.4/F1.5）。
- 新页面：工单（F1.2）、检测记录（F1.3）、环境监测（F2.1）、报警中心（F2.2）、用水月报（F2.3）、运行计划（F3.1）、自评表（F3.2）。
- 导航：沿用现有 `/pod/deviceManager/...#/<route>` 模式新增入口。
