# 02 · 功能清单

> 由 `01-需求定义.md` 派生。优先级：P0 = 控制项/高分项且为后续功能前提；P1 = 高分评分项；P2 = 增强。
> 每期功能必须带验收口径，完成标准见需求文档对应条目。

## P0 — 第一期：证据链与数据地基

| 编号 | 功能 | 需求 | 说明 |
|---|---|---|---|
| F1.1 | 设备档案扩展 | R1 | 台账新增验收日期/投用日期/能效等级/额定参数字段；详情页新增「档案」区 |
| F1.2 | 运维工单 | R2.1 | 工单列表/创建/执行/关闭；设备时间线聚合工单+检测记录 |
| F1.3 | 定期检测记录 | R2.2 | 检测对象枚举（饮用水/医疗用水/医用气体/空调/污水/室内环境/射线防护）；结论与附件引用 |
| F1.4 | 实时值接入 | R3.1 | FIN 模式读 point 的 curVal，详情页实时读数 |
| F1.5 | 历史接入 | R3.2 | hisRead 日/周/月/年曲线；沿用"无历史显示暂无"原则 |
| F1.6 | 记录写入通道 | R2.3 | 经 FIN 的只增不改记录写入（工单/检测），含防重放保护（沿用 seed 的 dataset 防重放思路） |

## P1 — 第二期：能源与环境（冲分项）

| 编号 | 功能 | 需求 | 说明 |
|---|---|---|---|
| F2.1 | 计量点模型与看板 | R4 | 分区/分项能耗看板、占比、逐日逐月逐年查询、下钻到点 |
| F2.2 | 能耗同比分析 | R5.1/R5.2 | 用电/水/气分账、同比百分比、>10% 高亮 |
| F2.3 | 能源审计与奖惩记录 | R5.3/R5.4 | 审计登记、整改项关联工单、奖惩登记 |
| F2.4 | IAQ 监测 | R6.1 | CO2/PM2.5 等点位按房间归属，实时+历史 |
| F2.5 | 报警规则与事件流 | R6.2/R6.3/R6.4 | 阈值规则、报警触发/确认/关闭、与排风联动状态标记 |
| F2.6 | 用水分项与非常规水源 | R7 | 用水分项月报、中水/雨水利用记录 |

## P2 — 第三期：管理闭环

| 编号 | 功能 | 需求 | 说明 |
|---|---|---|---|
| F3.1 | 运行计划管理 | R8 | 按系统建计划、执行登记、年度考核汇总 |
| F3.2 | 可再生能源记录 | R5.5 | 利用量登记与统计 |
| F3.3 | 绿色医院自评表 | R9 | 9.3 评分表数字化、证据挂接、导出 |

## 功能—页面映射（初稿）

- 设备详情页：新增「档案」「运维记录」标签；点位区显示实时值与历史曲线。
- 新页面：运维工单、检测记录、能耗看板、同比分析、审计记录、环境监测、报警中心、运行计划、自评表。
- 导航：End User 菜单新增以上入口（或二级导航），沿用现有 `/pod/deviceManager/...#/<route>` 模式。
